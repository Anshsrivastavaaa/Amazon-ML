# Amazon ML Challenge

Repository for participating in the Amazon ML Challenge.

## Project Structure

```
Amazon-ML-Challenge/
├── data/
│   ├── raw/            # Original competition datasets (train.csv, test.csv, etc.)
│   └── processed/      # Preprocessed features and cleaned data
├── models/             # Saved model checkpoints and weights
├── notebooks/          # Jupyter notebooks for EDA and experimentation
├── src/                # Source code and modular scripts
├── submissions/        # Generated submission CSV files
├── .gitignore          # Git ignore rules for data, models, and cache
└── requirements.txt    # Python dependencies
```

## Setup

1. **Create and activate a virtual environment**:
   ```bash
   python -m venv venv
   .\venv\Scripts\activate
   ```

2. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```
